How to read the results

Completion Time (CT): time at which a process finishes.

Turnaround Time (TAT): total time from arrival to completion.

TAT = CT − AT

Waiting Time (WT): time spent waiting in the ready queue.

WT = TAT − BT

Average TAT / WT: average of the corresponding process values.

Operating Systems Lab Procedure

AIM

To implement and compare CPU scheduling algorithms (FCFS, non-preemptive SJF, Round Robin and a simplified three-level MLFQ) and calculate completion time, turnaround time and waiting time.

Algorithm / Pseudocode

1. Read number of processes and each process's ID, arrival time and burst time.
2. Select a CPU scheduling algorithm.
3. Sort/choose ready processes according to the selected algorithm.
4. If no process has arrived, move the CPU clock to the next arrival time.
5. Execute the selected process:
   FCFS: run it until completion.
   SJF: choose the arrived process with the shortest burst time.
   RR: run for at most one time quantum; re-queue if unfinished.
   MLFQ: use Q1, Q2 and Q3 in priority order; demote unfinished work.
6. Record each execution interval and each process's completion time.
7. For every process calculate:
   TAT = CT - AT
   WT  = TAT - BT
8. Display the Gantt chart, process table and averages.

C reference code (FCFS)

#include <stdio.h>
int main() {
    int n, i, j, at[20], bt[20], ct[20], tat[20], wt[20];
    int t = 0, temp;
    printf("Enter number of processes: ");
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        printf("Enter arrival and burst time: ");
        scanf("%d%d", &at[i], &bt[i]);
    }
    /* Sort by arrival time (stable for equal arrivals). */
    for (i = 0; i < n; i++)
      for (j = i + 1; j < n; j++)
        if (at[j] < at[i]) {
          temp=at[i]; at[i]=at[j]; at[j]=temp;
          temp=bt[i]; bt[i]=bt[j]; bt[j]=temp;
        }
    for (i = 0; i < n; i++) {
        if (t < at[i]) t = at[i];
        t += bt[i];
        ct[i] = t;
        tat[i] = ct[i] - at[i];
        wt[i] = tat[i] - bt[i];
    }
    printf("PID\\tCT\\tTAT\\tWT\\n");
    for (i = 0; i < n; i++)
      printf("P%d\\t%d\\t%d\\t%d\\n", i+1, ct[i], tat[i], wt[i]);
    return 0;
}

FAQ

Why can the CPU be idle?

The CPU is idle when no process has arrived or is ready to execute.

Which algorithm is preemptive?

Round Robin and this simplified MLFQ can interrupt a running process. FCFS and the SJF version here are non-preemptive.

Why is SJF sometimes unfair?

Long processes may wait for a long time if short processes keep arriving. This is called starvation.

What does the time quantum mean?

It is the maximum continuous CPU time given to a process in one Round Robin turn.

Is this MLFQ identical to every operating system?

No. MLFQ policies vary. This teaching model has three queues, fixed quanta and demotes a process when it uses its full time slice.
